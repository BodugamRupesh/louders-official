Frequently Asked Questions

Got questions? We have cyber-grade answers.

How does device binding work?
When a user activates a license, their browser and operating system details are gathered and assigned a UUID. Future checks verify the UUID matches the license parameters. If the max device limit is reached, registrations fail.
Can I integrate this with stripe?
Yes, our API includes webhooks and routes to create licenses instantly upon Stripe Checkout completions. Simply call the `/api/v1/licenses` endpoint using your Product API Key.
Are license tokens secure?
Yes. On activation, the system issues a temporary JWT containing verification scopes. Extensions use this JWT token in memory, meaning your database remains protected from request spikes.
